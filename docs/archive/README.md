# Historical design notes

This directory contains early design and implementation notes kept for context.

They are **not** current product specifications, API contracts, or implementation guides. When they conflict with source code, OpenAPI, or the root README, the current implementation takes precedence.

Current records:

- `early-mvp-requirements.md` — early MVP product and architecture thinking.
- `backend/web-crawl-development-spec.md` — background material for the initial web-crawl design.
- `frontend/ui-scope-constraints-draft.md` — early frontend scope and navigation draft.
- `frontend/console-project-workflow.md` — implementation notes for an earlier Project console loop.
