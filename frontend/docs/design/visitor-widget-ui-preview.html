如何把 TadaAsk Widget 嵌入到静态文档站点？

把 Widget 脚本放到站点的公共布局中，并为组件传入项目与部署标识。这样每个生成页面都会加载同一个助手实例。1

推荐步骤

  • 在全局 layout 的结束标签前加载 Widget 脚本。
  • 添加 <tada-ask-widget> 标签并配置必要属性。2
  • 确认当前站点 Origin 已在对应 Widget 部署中启用。3

样式层面只覆盖公开的语义变量，消息、Markdown 与引用交互会继续由组件内部控制。4

页面刷新后还会保留这次对话吗？

不会。Widget 只维护当前页面生命周期内的一轮可见会话；折叠再打开仍会保留，但刷新页面或点击新会话后，上一轮消息不会重新加载。

RAG Snapshot 在流式回答中是怎样工作的？
Writing answer

rag_ready 会先于文本 delta 到达，因此前端能在回答生成期间提前获得有效 citation ID。1

之后每个 delta 只追加正文内容；当完整的 [[citation:N]] marker 出现时，渲染器会把它转换为可点击的引用编号，同时隐藏尚未闭合的尾部片段。
