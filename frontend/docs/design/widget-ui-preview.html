FastAPI documentation sample page

This static page exists only to show how the TadaAsk visitor widget feels when embedded into a documentation site. The widget in the bottom-right corner uses local demo state and does not call a backend.

<script src="https://example.com/tadaask-widget.js" data-project="project_fastapi_docs" data-widget="widget_fastapi" data-title="FastAPI AI Assistant"> </script>

Why this preview is useful

The widget is intentionally closer to a reading panel than a narrow chat bubble. RAG answers often need more room for Markdown content, code examples, tables, and visible source cards.

  • The header keeps title and logo visible at all times.
  • The answer area supports a Markdown-shaped layout.
  • Sources use a compact capped list with expandable local excerpts.
  • Mobile rendering is hidden for MVP.
